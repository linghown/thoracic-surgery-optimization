# 胸外科手术优化技巧

> 基于单孔胸腔镜实战经验的手术优化知识库，持续积累，持续迭代。

## 关于本仓库

本仓库记录胸外科手术中的实战优化技巧，聚焦于**缩短手术时间、提升操作安全性**。内容来自真实手术中的反复验证，不是教科书翻译，而是**踩坑后的经验总结**。

## 目录结构

```
├── 肺叶切除术/          # 各肺叶切除优化
│   ├── 右上肺叶切除/    # 上肺静脉处理等
│   ├── 右下肺叶切除/    # 下叶支气管处理等
│   ├── 左上肺叶切除/
│   ├── 左下肺叶切除/
│   └── 通用技巧/        # 牵拉策略、肺萎陷应对等

├── 袖式切除术/
├── 食管癌手术/
│   ├── 二野清扫/
│   └── 三野清扫/
├── 纵膈手术/
└── 其他手术/
    ├── 手汗症/
    ├── 漏斗胸/
```

## 使用方式

- 每个目录下的 Markdown 文件即为该手术/步骤的优化要点
- 标注 ✅ 的技巧为已在实际手术中验证
- 标注 💡 的为理论推演、待验证
- 欢迎补充和纠错

## 核心原则

1. **安全优先**：任何优化不以牺牲安全为代价
2. **实战验证**：不写没做过的手术
3. **简洁直接**：去掉教科书内容，只写"怎么做得更好"

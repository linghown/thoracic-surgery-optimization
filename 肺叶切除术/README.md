## 通用原则

1. **不需要全部360°裸化**：静脉和支气管——前壁+两侧壁清晰即可安全过钉
2. **遇到阻力先问为什么**：解剖变异？淋巴结粘连？角度不够？
3. **角度补偿**：30°镜多旋转，找到每个结构的最佳视角
4. **速度快 ≠ 手术快，流程顺才是真的快**
